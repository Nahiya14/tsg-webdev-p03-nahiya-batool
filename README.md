# LUMA Journal

LUMA Journal is a responsive multi-page editorial blog website created as **Project 03** for my Web Development Internship at **The Sky Gen**.

The website focuses on travel, culture, architecture, design, and everyday observations. It uses a clean editorial style with large typography, soft colours, photography, and magazine-inspired layouts.

## Pages

The website contains three main pages:

- **Home** — introduces LUMA Journal, highlights a featured Istanbul story, and displays selected stories.
- **Journal** — displays four blog stories using an editorial magazine-style layout.
- **Contact** — includes contact information and a styled contact form.

## Design Concept

The design of LUMA Journal was inspired by modern editorial magazines and travel journals.

The visual style uses:

- Dark navy for strong sections and navigation
- Soft neutral backgrounds
- Dusty rose accents
- Serif typography for editorial headings
- Sans-serif typography for body text
- Large photography
- Asymmetrical magazine-style layouts
- Minimal decorative details

The goal was to create a website that feels professional, calm, elegant, and visually different from a basic blog layout.

## Responsive Design

The website was designed to work across different screen sizes.

The layouts were adjusted for:

- Desktop
- Tablet
- Mobile devices

On smaller screens, multi-column sections stack vertically to prevent horizontal scrolling and keep the content readable.
